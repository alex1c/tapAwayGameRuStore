# Required Unity version (both PCs)

**Unity 6000.3.22f1** — Unity 6.3 LTS

Install via Unity Hub:

1. Editor: `6000.3.22f1`
2. Modules:
   - Android Build Support
   - Android SDK & NDK Tools
   - OpenJDK

Do not use beta / alpha / tech-stream builds for this project.

After install, open this repository folder as a Unity project and let it
regenerate `Library/` (ignored by git). Then run EditMode tests.
